# CLAUDE.md

Agent guidance for this repo lives in **[AGENTS.md](AGENTS.md)**. Read it first: what the project
is, how the specs and docs are written, and commit attribution (`Assisted-by:`, never
`Co-Authored-By:`). F01 adds the predecessor's guide below it: design doctrines (486-minimalism,
all-static, no-Python, bitmap-only/no-freetype), PAT handling for workflow pushes, debugging
discipline and the traps-and-recipes knowledge base.

`SPEC.md` is the authority on what is built. The work is split into nodes (`docs/graph.yaml`, one
spec each in `nodes/`), and `docs/first-release.md` is the plan. `MYTH.md` says why it exists.
