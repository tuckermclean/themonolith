# Revision v0.5 — 2026-10-29

## Why

Starting F01 under v0.4 showed that the spec imported the whole predecessor tree (201 files) in one
node, with its history behind a merge commit, and changed it afterwards. The owner's model is
different: **write the tests, then port in the code needed to pass them.** Under v0.4, F01's tests
mostly checked the copy (hashes, dropped files, disabled workflows) rather than behaviour, and
F01-AC-4's grep for dropped paths contradicted the rule that imported files stay verbatim.

## What changed

- **SPEC §0, §2.2:** each node writes its tests, then ports the predecessor code they need. A node's
  fast tests stay in the lane, so a rule set early (no AWS, SHA-pinned actions, the builder by digest)
  holds for code ported later.
- **`docs/capabilities.md` (new):** every capability, the node that owns it, and whether it is ported,
  fixed, built, replaced or dropped. It accounts for all 201 predecessor files and replaces
  `IMPORT.md`.
- **SPEC §4.2:** path owners follow the ledger instead of F01.
- **SPEC §10, §11:** OD-11 is gone. The predecessor's history stays in the predecessor; a porting
  commit names its sources as `path:line` at `b9f533b`. No merge-commit exception.
- **F01 (renamed `fast-lane`):** `make test`, `pr-validate.yml` in the parity form, SHA pinning,
  Dependabot, CODEOWNERS, `.gitignore`, and the predecessor's agent guide. No bulk import, no
  disabled workflows, no `IMPORT.md`.
- **I01:** a standing no-AWS check plus the `REGISTRY` variable. Each porting node leaves S3 out of
  what it ports; I01's table says which. Its binpkg-store criteria moved to B01 (B01-AC-17, -18).
- **R01:** ports all of `monolith-base` with its nine tests before B01. The os-release URL moved to
  B03 (B03-AC-8); the `versions.lock` line to B01.
- **B01:** ports the distribution policy and the overlay packages `world` needs, the kernel as it is;
  depends on R01.
- **B02:** depends on B01 and changes the kernel B01 ported; the inline module checks of `build.yml`
  become `scripts/verify-kernel-modules.sh` (B02-AC-8), and B02-AC-9 forbids `configs/kernel.config`.
  Its slow criteria run locally in the builder image.
- **I03:** the `build.yml` and `attestation.sh` edits moved to B03 and S01, held by I03's test.
- **O01:** ports the manual QEMU targets as `test-bios` and `test-uefi` (O01-AC-6).
- **M01, M02, P03, R03, R05, G01, S01:** wording for what they port versus change.
- **Plan:** the MS1 chain is F01 → I01 → I02 → B01 → B02 → B03 (six nodes; twelve lead to MS1).
- **Tooling:** the `/node` skill and role agents check ported files against their `b9f533b` blob
  instead of `IMPORT.md`. A predecessor test ported verbatim may fail RED only because its subject is
  not ported yet.
