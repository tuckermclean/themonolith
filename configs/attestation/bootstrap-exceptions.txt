# Files in the root filesystem that the crossdev toolchain installs from host-side
# cross-i486-linux-musl/* packages. The target VDB does not own them; the host VDB does, found
# with `qfile` on the host root at the path under /usr/i486-linux-musl (the crossdev sysroot) in the
# pinned builder, BUILDER_DIGEST in the Makefile. out/node/B01/qfile.log records the run.
#
# Format: <absolute path> <host cpv>. The path is everything before the last space. The cpv's
# version equals configs/portage/crossdev.lock, without its -rN.
# Nothing else may be listed: a preinstalled package that cannot be re-merged in the sysroot is a
# finding to fix, not an exception. Read by scripts/source-audit.sh and check-unowned.py (both modes).

# The musl libc.so, copied by build-packages.sh to the dynamic linker path (R03 removes it).

# The ldd symlink and the libc.so itself, exported from the crossdev sysroot.

/usr/lib/libc.so cross-i486-linux-musl/musl-1.2.6-r2
